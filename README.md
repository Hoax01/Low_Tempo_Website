# Low Tempo — vintage website

Open `index.html` directly in a browser. The collection includes four ready-made bundles: Starry beats, Cotton candy, Silver lining, and Strawberry shortcake. It also has a mix-and-match custom order ticket and past custom-order inspiration. Bundle and custom selections go into a browser-local demo bag.

The Memory Wall has six sample cards using the supplied photographs. Visitors can flip each card to read a sample feeling, or choose a JPG, PNG, or WebP photo and write their own. Added memories are resized and saved only in that browser; there is no shared upload server. The story section uses one of the supplied flower photographs.

The bundle and memory photographs were supplied for this project. Product availability, prices, checkout, and shared customer posting are illustrative. `theme.css`, old SVGs, and earlier sample JPEGs in this local folder are unused drafts; the ZIP contains only active website files and the bundled font.
